# SEC-01 Rebuild-from-Memory Challenge

## RFS-SEC-01

**Time limit:** 20 minutes  
**Materials:** Blank paper or text editor. No compiler required for pass — oral follow-up verifies.

### Deliverable

From memory, produce:

1. Five pipeline stages (named, ordered)
2. Diagram: two `.cpp` → two `.o` → linker → executable → loader → `main`
3. Three vocabulary definitions: TU, object file, symbol
4. One compile error example + one linker error example (messages you write, not copy)
5. Commands for: preprocess-only, compile-only, link-only (generic filenames)

### Oral follow-up (5 min)

- "You have `undefined reference to X`. Which stage? What do you check?"
- "Why does separate compilation exist?"

### Pass criteria

≥4/5 written sections correct; both oral questions answered without hesitation.

### Remedial if fail

Re-do practice I1–I2; redraw diagram daily for 3 days; retry.
