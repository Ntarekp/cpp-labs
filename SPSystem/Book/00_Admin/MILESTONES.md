# Milestones

> Milestones are **evidence-based checkpoints**. Completing a project ≠ achieving a milestone.

## Milestone Map

```mermaid
timeline
    title University Milestones (typical 3.5-year path)
    section Year 1
        M0 University enrolled : Charter approved
        M1 Construction fundamentals : SEC-01 to 12 + FE-A1
        M1b Theory foundations : CST-01 03 05 + FE-B1
        M2 Merge complete : Phase 2 unlocked
        M3 C++ mechanism mastery : FE-02 passed
        M4 DSA implementation : FE-03 passed
    section Year 2
        M4 OOP + Patterns : FE-04 + FE-05 passed
        M5 First lab rebuilt : LAB-01 mastered
        M6 Architecture thinker : FE-06 passed
        M7 CP foundation : CP-T3 passed
    section Year 3
        M8 Systems programmer : FE-07 + FE-12 passed
        M9 Persistence expert : FE-11 + FE-13 passed
        M10 Domain portfolio : 4 labs mastered
        M11 OSS reader : 3 codebases studied
    section Year 4+
        M12 Capstone architect : CAP-02 passed
        M13 Graduation candidate : All FE + 6 labs
        M14 GRADUATED : Oral + CAP-05 passed
```
