INTEGRATED SITUATION
Kigali City is experiencing serious challenges in its public parking areas due to
a manual ticket-based parking system. Attendants issue paper tickets and
record entries by hand, which often causes long queues at the entrance, poor
allocation of parking spaces, and frequent disputes about parking fees.
Because there is no real-time visibility of available slots, drivers waste time
circulating, which increases congestion and reduces customer satisfaction. In
addition, manual tracking creates opportunities for revenue leakage and
makes daily reporting unreliable.
To solve these problems, the Kigali City plans to introduce a Smart Parking
Management System that provides real-time slot allocation and accurate
billing. The system must automatically manage:
● parking slot configuration and availability,
● vehicle entry registration,
● parking duration tracking and fee calculation,
● vehicle exit and payment recording,
● operational reports such as available slots, parked vehicles, vehicle
history, and daily revenue.
You have been hired as a Data Structure and Algorithms expert using C++ to
design and implement this solution using in-memory data structures only (no
database required). The system should be efficient and scalable, demonstrating
correct use of Data Structures and Algorithms (DSA) and good OOP design
practices.2.0 TASKS

Task 2: Vehicle Entry Management
Implement vehicle entry registration with:
● Vehicle plate number (unique)
● Vehicle type(Car, Truck, Motorcycle)
● Entry time
● Allocated parking slot
Requirements
● A vehicle cannot be parked more than once at the same time.
● If no suitable parking slot is available, the system must handle the

● Students must choose appropriate data structures to manage vehicle
records and slot assignments.Task 3: Parking Duration and Fee Calculation
Implement logic to:
● Calculate parking duration based on entry and exit time
● Apply parking rates based on vehicle type
● Compute the total parking fee
● Allow update of parking price
● Price updates must not affect previously completed parking records.
Rules
1. The system must start with default hourly parking prices for each vehicle

2. The system must provide a controlled option to update parking prices

3. Parking fees must always be calculated using the current active prices at
the time of vehicle exit.
4. Price updates must not affect already completed parking transactions
recorded in history.
Default starting Tariffs
